# Your images

Two ways to add photos to the site:

1. **Admin panel (recommended)** — every image field (profile photo, project covers, certificate
   badges, testimonial photos) has an **Upload image** button. Files go to `server/uploads/`.

2. **This folder** — drop files here (e.g. `me.jpg`, `project-shop.webp`) and paste the path
   `/images/me.jpg` into any image field in the admin panel.

Tips: use `.webp` or `.jpg`, keep photos under ~500 KB, square for the profile photo,
4:5 portrait for the About photo, 16:9 (1280×720) for project covers.
